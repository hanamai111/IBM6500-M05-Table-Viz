# M05 — Visualizing Data with Tables for MSDM CEP

Han Mai · IBM 6500

Quarto report using the synthetic `gt::pizzaplace` teaching dataset. The report demonstrates `gt` and `gtExtras` methods that can later support PhD Orthodontics Google Ads analysis; pizza findings are not client performance data.

Open `M05.Rproj`, then `Mai, Han-M05-Table-Viz.qmd` in RStudio and select Render. Required R packages: dplyr, tidyr, gt, gtExtras, knitr, rmarkdown, downlit, and xml2.

The named HTML file is the submission deliverable. `index.html` is an identical copy used as the GitHub Pages entry point; refresh that copy after rendering updates.
